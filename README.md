# Cadenza Music Therapy - Standalone Website

A website for Cadenza Music Therapy, providing information about services, scheduling, and contact details.

## Overview

This is the standalone website for Cadenza Music Therapy, built to showcase services and allow client engagement.

## Getting Started

### Prerequisites
- Node.js (if using npm)
- A modern web browser

### Installation

```bash
# Clone the repository
git clone https://github.com/cadenzamusictherapyadmin/StandaloneWebsite.git
cd StandaloneWebsite

# Install dependencies (if applicable)
npm install
```

### Development

```bash
# Start development server
npm run dev
```

### Building

```bash
# Build for production
npm run build
```

## Project Structure

- `/public` - Static assets (images, fonts, etc.)
- `/src` - Source code
- `/docs` - Documentation
